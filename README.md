# Python Expense Tracker

A simple Python Expense Tracker that allows users to enter multiple expenses and calculates the total amount spent.

## Features

- Enter multiple expenses
- Type `done` to finish entering expenses
- Calculates the total amount spent
- Simple command-line interface

## How to Run

Run the `task 2.py` file using Python.

## Example

Enter expense (or type 'done' to finish): 100
Enter expense (or type 'done' to finish): 50
Enter expense (or type 'done' to finish): 20
Enter expense (or type 'done' to finish): done

Total Spent: 170.0
