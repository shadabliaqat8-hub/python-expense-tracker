# Python Internship Projects

This repository contains my Python projects completed during my internship at DecodeLabs.

## Project 2: Expense Tracker

A simple Python Expense Tracker that allows users to enter multiple expenses and calculates the total amount spent.

### Features
- Enter multiple expenses
- Type `done` to finish entering expenses
- Calculates the total amount spent
- Simple command-line interface

### How to Run
Run `task 2.py` using Python.

### Example
Enter expense: 100
Enter expense: 50
Enter expense: 20
Enter expense: done

Total Spent: 170.0

## Project 3: Random Password Generator

A Python tool that generates a random password based on the length entered by the user.

### Features
- User enters the required password length
- Uses Python `random` and `string` modules
- Generates passwords using letters and numbers
- Produces a different random password each time

### How to Run
Run `task 3.py` using Python.

### Example
Enter Password length: 8
Generated Password: 0qBtKEY6
